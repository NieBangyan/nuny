# 课堂练习首页

首页 `/system/main` 使用 `/system/classroom/report?date=yyyy-MM-dd` 查询真实数据。

1. 在“学生名册”输入姓名和座位排号后添加学生。姓名用于关联原有课堂记录，同名学生需添加学号后缀区分。
2. 选择日期，页面显示完整名册。无当日记录的学生计为未完成；同一天有多条记录时，取 ID 最大的一条。
3. 点击学生卡片切换完成状态；调整排号作用于名册，历史日期也按当前座位分组。
4. 各排按完成人数倒序，同人数按排号升序。柱状图显示当前筛选范围的已完成和未完成人数。

权限沿用课堂记录：`system:records:list` 查看，`system:records:add` 添加学生，`system:records:edit` 调整排号和标记完成。管理员默认可用。

首次部署先执行 `sql/classroom_report.sql`，它仅创建缺失的表，不清空已有记录。升级前备份数据库和旧 JAR。
